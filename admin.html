Settings & Setup

Google Sheets + Apps Script Setup

You need one Google Spreadsheet with Products and Orders tabs.

1. Products Sheet – Headers (Row 1)

id | name | range | price | oldPrice | image | image2 | image3 | badge | description | notes | stock | active | testerPrice

2. Orders Sheet – Headers (Row 1)

id | orderId | customerName | phone | email | address | city | items | total | status | createdAt | notes

3. Deploy Apps Script Web App

  1. Go to Google Apps Script → Sign up (free)
  2. Create API → connect Products Google Sheet → copy API ID
  3. Create another API → connect Orders Google Sheet → copy API ID
  4. Paste the Web App /exec URL in js/config.js as APPS_SCRIPT_URL

4. Current Config

Apps Script URL: Not set

Orders: Not set

Image upload (ImgBB): Not set

Edit js/config.js to update API keys and admin password.

5. Product image uploads

Admins upload PNG / JPG from their computer. Images go to ImgBB and the public URL is saved to the Products sheet automatically.

  1. Go to api.imgbb.com → free sign-up
  2. Copy your API key
  3. Paste it as IMGBB_API_KEY in js/config.js

Accepted formats: PNG, JPG, JPEG only. Max size set by IMAGE_MAX_MB (default 8).

Bulk Upload (Excel)

On the Products tab you can:

  • Download an Excel template (with sample rows + instructions)
  • Upload a filled .xlsx / .xls / .csv to add or update many products at once

Required columns: name, price, image. Leave id empty for new products.
